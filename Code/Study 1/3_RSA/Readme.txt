This folder contains Representational Similarity Analysis (RSA) scripts that compare representational structures across groups using Mantel tests.

Files:
- unfair_7var_rsa_mantel_analysis.py: Main RSA analysis script. Computes representational matrices for 7 variables (choice, AA_valence, AA_arousal, AC_valence, AC_arousal, EmoFDBK_valence, EmoFDBK_arousal) and performs Mantel tests to compare matrices between human and LLM groups.
- unfair_7var_rsa_mantel_visualization.py: Visualization script that reads analysis results and generates network plots showing RSA correlation matrices.
- demo.xlsx: Input data file (demo data for testing/validation purposes) containing raw experimental data with 7 emotion and choice variables.
- processed_rsa_data.xlsx: Processed output data file containing mean values for all datasets with 7 emotion and choice variables (generated by unfair_7var_rsa_mantel_analysis.py).

DATA FILE NOTE:
This analysis uses demo.xlsx as input data file, which contains a subset of the full dataset
(5 participants per group: human, gpt3.5, o3, V3, R1).

To use the full dataset:
1. Access the full dataset at: [INSERT LINK HERE]
2. Download the file named "Study1_experimental_data.xlsx"
3. Replace "demo.xlsx" with "Study1_experimental_data.xlsx" in the unfair_7var_rsa_mantel_analysis.py script
   (modify the input_file path in the main() function)

Note: When switching to full data, you may need to adjust:
- Computation time may increase significantly (especially for Mantel test permutations)
- Memory usage may increase
- RSA matrix calculations will be based on more participants per group

Usage:
1. Ensure demo.xlsx is in the current directory (or use Study1_experimental_data.xlsx for full analysis - see DATA FILE NOTE above).
2. Run the RSA analysis script first:
   python unfair_7var_rsa_mantel_analysis.py
3. Then run the visualization script:
   python unfair_7var_rsa_mantel_visualization.py

Output:
- processed_rsa_data.xlsx: Processed standardized mean data
- unfair_7var_rsa_mantel_correlations.csv: RSA Mantel correlation matrix
- unfair_7var_rsa_mantel_pvalues.csv: RSA Mantel p-value matrix
- unfair_7var_rsa_pearson_correlations.csv: Pearson correlation matrix
- unfair_7var_rsa_pearson_pvalues.csv: Pearson p-value matrix
- unfair_7var_rsa_mantel_visualization.png: Visualization plot showing RSA correlation matrices

Note: RSA analysis compares the similarity of representational structures (correlation matrices) between groups. The Mantel test evaluates whether two representational matrices are significantly correlated.
