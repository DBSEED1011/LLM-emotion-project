This folder contains mediation analysis scripts that examine mediation effects for unfair conditions.

Files:
- process_unfair_data.py: Python script to filter unfair condition data from demo.xlsx. Filters data where amount_of_allocation is between 10-14 (inclusive) and saves as unfair_data_for_mediation.xlsx.
- mediation_analysis.R: R script for mediation analysis. Analyzes mediation effects of emotion variables on the relationship between allocation/cost and choice outcomes under unfair conditions. Uses standardized variables and group-wise analysis.
- demo.xlsx: Demo data file containing a subset of the full dataset (5 participants per group: human, gpt3.5, o3, V3, R1).
- unfair_data_for_mediation.xlsx: Input data file for mediation analysis, containing filtered unfair condition data (generated by process_unfair_data.py).

DATA FILE NOTE:
This analysis uses demo.xlsx, which contains a subset of the full dataset (5 participants per group).

Usage:
1. Run process_unfair_data.py to filter unfair condition data from demo.xlsx (generates unfair_data_for_mediation.xlsx).
2. Ensure unfair_data_for_mediation.xlsx is in the current directory.
3. Open mediation_analysis.R in R or RStudio.
4. Run all code chunks to perform mediation analysis.

Output:
- unfair_data_for_mediation.xlsx: Filtered unfair condition data
- Mediation effect estimates
- Direct and indirect effects
- Statistical significance tests
- Visualization plots

Note: The analysis splits data by groups (human, GPT-3.5, o3-mini, DeepSeek-V3, DeepSeek-R1) and performs group-wise standardization of emotion and fairness variables before mediation analysis.
